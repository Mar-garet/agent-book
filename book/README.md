# 阅读路线：从零走向设计判断

第一次接触 Agent，可以按顺序读。已有使用经验，可以先读开篇，再到第十章检查自己如何比较项目；遇到不熟悉的概念，再回到对应章节。

这份书稿的主线是一项贯穿案例：一家团队每天需要排查报表失败、准备修复方案，并向使用者提供可以核查的结果。任务会逐渐变长，会碰到错误、变更和权限限制。读者将看到，每加入一种困难，系统就需要承担一种新责任。

案例是为了讨论机制而设计的情境，不代表任何项目的实际运行结果。

## 当前覆盖范围

本轮写到了概念、机制与设计推断，并初查了代表项目的官方材料与部分源码入口。已经形成 Pi 与 Deep Agents 的默认机制比较、LangChain 生态层次比较、三种记忆职责的比较，以及结构化工具调用与代码行动的比较。

32 个项目中的其余案例保留在项目地图中，标明需要继续研究的问题。运行成功率、延迟、成本、长任务稳定性，以及具体实现中的边界情况，需要按第十一章的方法实际实验，当前没有虚构测量值。
