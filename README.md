<h1 align="center">Agent Book</h1>

AI Agent 怎样从回答问题走向完成任务？模型负责决定下一步，运行系统负责调用工具、保存状态，并把执行结果交回模型。一旦任务变长，系统还需要处理上下文不足、行动失败、任务交接与中断恢复，最终判断工作是否真正完成。

Agent Book 是一本从零到深入理解 AI Agent 的开源中文书，面向希望弄懂 Agent 工作原理的初学者、正在使用 Agent 的开发者，以及准备设计和构建 Agent 系统的工程师。

本书从模型、工具与运行系统的关系讲起，逐步深入执行循环、工具调用、MCP、上下文与记忆、规划、Skills 和多 Agent 协作，再讨论权限边界、错误重试、执行恢复、资源预算与评测。贯穿全书的问题是：谁决定下一步，谁执行行动，谁保存状态，又由谁检查结果？

书中以开源项目和固定版本的源码为案例，结合可复现的机制实验，解释不同设计为何出现、解决了什么问题，以及带来哪些代价。希望读者不仅能看懂一次演示，也能判断一个 Agent 系统在真实任务中是否可靠。
