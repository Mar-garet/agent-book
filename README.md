<h1 align="center">Agent Book</h1>

Agent Book 是一本从零到深入介绍 AI Agent 的开源中文书。本仓库收录书稿、研究资料和实验记录，以开源项目的源码为依据，解释 Agent 如何工作，以及不同设计背后的取舍。

内容涵盖 Agent 执行循环、工具调用、MCP、上下文与记忆、规划、Skills、多 Agent 协作、执行恢复与评测。
